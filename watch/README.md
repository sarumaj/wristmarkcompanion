# Watch app

The Connect IQ device app that shows the marker. It is built from milestone 2 on. So far only
`source/MarkerDictionary.mc` exists: it is generated by `tools/generate-dictionary.mjs`, so don't
edit it ([decision 002](../docs/decisions/002-marker-dictionary.md)).

Building it needs the Connect IQ SDK, which CI doesn't have yet ([docs/ci.md](../docs/ci.md)).
